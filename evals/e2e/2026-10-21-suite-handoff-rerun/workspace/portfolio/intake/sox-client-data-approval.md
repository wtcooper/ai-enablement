## The problem in one sentence

Take one narrow controls-testing use (user access recertification listing comparison and write-up first pass, one or two clients) through the 3-4 month client-data approval path so that a certified tool can later be used on client evidence.

## How often it happens

Once per tool and scope; no controls-testing case has gone through the path (reported). Not a recurring activity.

## Class

business-automation (an enabler for `sox-listing-tool` and `ct-int-listing-compare-draft`). It is a governance step, not a tool roll-out.

## Rules or AI

Not a question of rules versus AI; it is the approval that any client-data AI tool needs. AI is in scope for the later tool. Advisor values kept: `ladder: assist`, `runtime_class: shared-team-skills`.
