## The problem in one sentence

Have one specialist validate each key report once and record it in a register, so staff stop re-proving report completeness on every test.

## How often it happens

About 100-126 of 210 tests a month rely on a system report (12-15 of 25 controls used as a proxy for test share; reported, as relayed). Last month's record not yet obtained.

## Class

business-automation. Proposed by the portfolio, to confirm at screen.
