# Method index (ai-portfolio)

One file per step plus one cross-cutting file. Read a step file on entering that step. Shared method files (for
example interviewing and prioritize) live in `../../../transformation-advisor/references/method/index.md`.

| File | Step | When to read it | Summary |
|---|---|---|---|
| [setup.md](setup.md) | 1 Set up | When no portfolio exists, or the user wants to change scope, stages, roles or rhythm | Scope, inherited levers and weights, stage definitions, gatekeepers, gate paths, forum, rhythm, live limit |
| [intake.md](intake.md) | 2 Intake | A new idea, or an import from an advisor `opportunities.yaml` | One-sentence problem, class, owner, data, rules-or-AI and duplicate checks; import with back-link |
| [screen-and-score.md](screen-and-score.md) | 3 Screen and score | Items ready to screen | Pre-score gates, six scores split into value and readiness, quadrants, payback hurdles, the `g0` decision |
| [stage-gates.md](stage-gates.md) | 4 Stage gates | An item due at a gate, or a stop, hold or scale question | Six stages, gate evidence, Go, Kill, Hold, Recycle, stopping and retiring, handoffs; placeholder for acquired firms |
| [portfolio-review.md](portfolio-review.md) | 5 Portfolio review | A review is due, or "review our AI portfolio" | Pack, surfacing rules, stop and redirect evidence, rebalance, recording decisions |
| [value-tracking.md](value-tracking.md) | 6 Value tracking | An item approaches `g3`, or benefits figures are needed | Benefits register, counterfactual and attribution, capacity split, redeploy or reduce, portfolio measures |
| [people-and-change.md](people-and-change.md) | Any | Gatekeepers in a partnership, a contested stop, role evolution, a user's fear for their role | Portfolio-specific people guidance; points to the shared people-and-change method |
