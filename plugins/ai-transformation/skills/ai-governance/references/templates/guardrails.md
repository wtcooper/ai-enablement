# Guardrails

Extra rules for every skill in the suite. They add to the skills' ground rules and never weaken them. Written by
the ai-governance skill from `policy.md` (version <n>); change the policy first, then this file.

## Data

- <No client-confidential data in any tool outside a catalog entry approved for it.>
- <Regulated data (tax return information, privileged material) only in entries approved for that class, after the regime step in policy.md §6.>

## Review

- <Anything that leaves the firm is checked by a qualified reviewer first; citations are checked against the source.>
- <Tier-4 uses need an approval record before any pilot.>

## Profession

- <Run the independence screen before any AI work for, or tool shared with, an attest client.>
- <Section 7216 decision written down per workflow before return information enters a tool.>

## Tools

- <Recommend only catalog entries for their listed data classes and tiers; route anything else to the request path.>
- <New AI features inside existing software stay off for client work until they have a catalog entry.>
